# ROCCA Social — בוט תוכן ורשתות חברתיות

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/roccaartisrael-hue/Rocca-multi)

שירות שרץ 24/7 (לא אפליקציה מה-App Store), שמשתמש ב-Claude כדי לנסח פוסטים ותגובות,
ומפרסם אותם דרך ה-API הרשמי של כל רשת. אתם שולטים בכול דרך "דשבורד" נייד —
עמוד אינטרנט שמתקינים על מסך הבית של האייפון/אנדרואיד ונראה ומתנהג כמו אפליקציה,
בלי צורך בחשבון מפתח של אפל ובלי אישור App Store.

## מה זה עושה

- **כתיבת פוסטים**: כותבים נושא ("הגיע חומר אוניקס חדש"), בוחרים פלטפורמות —
  Claude כותב ניסוח מותאם לכל רשת (טון, אורך, האשטגים).
- **פרסום**: לחיצה אחת מפרסמת בפועל לפייסבוק / אינסטגרם / X, ומוסיפה "עדכון" לאתר ROCCA.
- **תגובות אוטומטיות**: תגובות חדשות בפוסטים, הודעות פרטיות בפייסבוק, ואזכורים ב-X
  מייצרות טיוטת תשובה אוטומטית. בברירת מחדל היא מחכה לאישורכם בדשבורד לפני שליחה
  (`AUTO_SEND_REPLIES=false`) — אפשר לשנות לשליחה אוטומטית לגמרי לאחר שבדקתם שהניסוחים טובים.
- **טיקטוק**: התשתית קיימת, אבל טיקטוק דורשת אישור (audit) של האפליקציה שלכם
  לפני שהיא מפרסמת בפועל לציבור — ראו הערה למטה.

## שלב 1 — מפתחות API

כל הפלטפורמות דורשות שאתם (בעלי החשבונות העסקיים) תיצרו אפליקציית מפתחים ותפיקו
מפתחות. אי אפשר לעקוף את זה — זו דרישה של הרשתות עצמן, לא מגבלה של הבוט.

### Claude (חובה)
1. https://console.anthropic.com → API Keys → צרו מפתח.
2. שימו ב-`ANTHROPIC_API_KEY`.

### פייסבוק + אינסטגרם (Meta)
1. https://developers.facebook.com → Create App → סוג "Business".
2. הוסיפו את המוצרים **Facebook Login**, **Webhooks**, ו-Instagram Graph API (העמוד
   העסקי בפייסבוק חייב להיות מקושר לחשבון אינסטגרם עסקי/creator).
3. דרך Graph API Explorer / Meta Business Suite הפיקו **Page Access Token** קבוע
   (long-lived) לעמוד העסקי → `META_PAGE_ACCESS_TOKEN`, `META_PAGE_ID`.
4. מזהה חשבון האינסטגרם העסקי → `META_IG_USER_ID`.
5. `META_APP_ID`, `META_APP_SECRET` מתוך הגדרות האפליקציה.
6. בחרו מחרוזת אקראית משלכם ל-`META_WEBHOOK_VERIFY_TOKEN` — תזינו אותה גם בהגדרות
   ה-Webhook באפליקציה (Callback URL: `https://<הכתובת-שלכם>/webhooks/meta`).
7. הרשמו ל-Webhook fields: `feed` (תגובות פייסבוק), `comments` (אינסטגרם), `messages`.

### X (טוויטר)
1. https://developer.twitter.com → צרו פרויקט + אפליקציה, הרשאות **Read and Write**.
2. הפיקו: API Key/Secret (`X_APP_KEY`/`X_APP_SECRET`) ו-Access Token/Secret עם הרשאות
   כתיבה (`X_ACCESS_TOKEN`/`X_ACCESS_SECRET`).
3. שימו לב: לרשתות X אין webhook חינמי לאזכורים — הבוט סורק אזכורים חדשים כל
   `X_MENTIONS_POLL_MINUTES` דקות (ברירת מחדל 15, כדי לא לחרוג ממכסת ה-API בתוכניות הזולות).

### טיקטוק (אופציונלי, יותר מסובך)
1. https://developers.tiktok.com → צרו אפליקציה, הוסיפו את המוצר **Content Posting API**.
2. עד שהאפליקציה עוברת audit של טיקטוק, פוסטים נשלחים רק כטיוטה פרטית ל"תיבה"
   של היוצר — לא מתפרסמים אוטומטית לציבור. זה תקין לבדיקות, לא לשימוש יומיומי.
3. `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, ו-`TIKTOK_ACCESS_TOKEN` (OAuth2 מול
   חשבון היוצר שלכם — יש להם מדריך "Login Kit" בתיעוד).

## שלב 2 — הרצה

```bash
cd server
cp .env.example .env
# ערכו את .env עם המפתחות שלכם, ובחרו DASHBOARD_TOKEN (סיסמה ארוכה משלכם)
npm install
npm run build
npm start
```

לפיתוח מקומי עם ריענון אוטומטי: `npm run dev`.

## שלב 3 — פריסה (כדי שהטלפון יוכל להתחבר מכל מקום)

השרת צריך לרוץ במקום נגיש באינטרנט עם HTTPS (חובה עבור Webhooks של מטא) — לא רק
על המחשב שלכם. הדרך הכי פשוטה בלי טרמינל בכלל:

### פריסה בקליק אחד ל-Render

יש בשורש הריפו קובץ `render.yaml` (Blueprint) שמגדיר הכול מראש.

1. היכנסו ל-https://render.com והתחברו עם GitHub.
2. "New +" ← "Blueprint" ← בחרו את הריפו הזה. Render יזהה את `render.yaml` לבד.
3. Render ייצור אוטומטית `DASHBOARD_TOKEN` ו-`META_WEBHOOK_VERIFY_TOKEN` אקראיים —
   תמצאו אותם בטאב "Environment" של השירות אחרי הפריסה.
4. עדיין בטאב "Environment", הזינו את שאר המפתחות (Claude, Meta, X, TikTOK) לפי
   ההוראות בשלב 1 למעלה, ולחצו "Save, rebuild, and deploy".
5. הכתובת הציבורית (`https://rocca-social-bot.onrender.com` או דומה) היא מה
   שתפתחו בטלפון בשלב 4.

> ⚠️ בתוכנית החינמית של Render אין דיסק קבוע — היסטוריית הפוסטים/התגובות
> (`server/data/`) מתאפסת בכל דיפלוי מחדש. זה לא משפיע על היכולת לפרסם, רק על
> ההיסטוריה בדשבורד. אם זה מפריע, שדרגו לתוכנית בתשלום (Starter, כ-7$/חודש)
> והפעילו את בלוק ה-`disk` המוער ב-`render.yaml`.

### חלופות

Railway.app או Fly.io עובדות באותה מידה טובה — צריך לחבר את הריפו, להגדיר
Root Directory ל-`server`, Build Command `npm install && npm run build`,
Start Command `npm start`, ולהזין את משתני ה-`.env` בממשק שלהם.

> ⚠️ ה-webhook של מטא ומשיכת התגובות/הודעות עובדים רק כשהשרת נגיש ב-HTTPS קבוע —
> לא כשהוא רץ רק על המחשב שלכם.

## שלב 4 — התקנת הדשבורד על הטלפון הייעודי

הדשבורד הוא PWA (Progressive Web App) — אותו קישור עובד גם באייפון וגם באנדרואיד,
בלי לעבור דרך App Store או Google Play, ובלי חשבון מפתח בשום פלטפורמה.

**אייפון (Safari):**
1. פתחו את `https://<הכתובת-שלכם>` בספארי (חובה ספארי — כרום לאייפון לא תומך בהתקנה).
2. הזינו את ה-`DASHBOARD_TOKEN` שקבעתם.
3. כפתור שיתוף (הריבוע עם החץ) ← "הוסף למסך הבית".

**אנדרואיד (כרום):**
1. פתחו את `https://<הכתובת-שלכם>` בכרום.
2. הזינו את ה-`DASHBOARD_TOKEN`.
3. תפריט שלוש הנקודות ← "התקן אפליקציה" (או באנר "הוסף למסך הבית" שיופיע אוטומטית).

בשני המקרים האייקון ייראה ויתפקד כמו אפליקציה רגילה: נפתח במסך מלא בלי סרגל כתובת,
עם אייקון משלו על המסך הראשי.

> 💡 אם בעתיד תרצו נוכחות רשמית ב-Google Play (למשל כדי שהאפליקציה תופיע בחיפוש בחנות),
> אפשר לעטוף את אותו דשבורד כ-Trusted Web Activity (TWA) עם הכלי `bubblewrap` של גוגל —
> זו עבודה נפרדת ונוספת, לא נדרשת כדי שהאפליקציה תעבוד על הטלפון.

## הערות בטיחות

- `AUTO_SEND_REPLIES=false` כברירת מחדל — כל תגובה אוטומטית מחכה לאישורכם.
  הפעילו `true` רק אחרי שבדקתם כמה תגובות ואתם סומכים על הניסוח.
- `AUTO_GIT_PUSH=false` כברירת מחדל — עדכוני האתר (`content/updates.json`) נכתבים
  לוקאלית אבל לא נדחפים ל-git אוטומטית, עד שתדליקו את זה במפורש.
- שמרו את קובץ ה-`.env` פרטי (הוא לא נכנס ל-git) — הוא מכיל מפתחות עם גישה מלאה
  לחשבונות שלכם.
- הדשבורד לא מוגן ב-HTTPS על ידי הקוד עצמו — ודאו שהשירות שבו תפרסו (Render/Railway/וכו')
  מספק HTTPS (כולם עושים זאת כברירת מחדל).
