# BOOL — מה נבנה ומה צריך מכם

מסמך זה מתאר את שדרוג rocca-social-bot לפלטפורמת BOOL. הקוד כולל בדיקות אוטומטיות (`npm run platform-check`, `platform-unit`, `tenant-check`, `tenant-unit`, `smoke`, `ui-check`).

## מה עובד
| רכיב | מצב |
|---|---|
| רב-לקוחות (נתונים נפרדים לכל עסק) | עובד, נבדק מול קבצים ו-Postgres |
| Freemium: 3 פעולות במתנה, בלי כרטיס | עובד. הרשמה → `free_trial` עם 3 קרדיטים |
| קרדיטים (`checkCredits`) | עובד. פעולת AI מוצלחת = קרדיט; נגמר → 402 עם הפניה לשדרוג. חבילות עסקים ללא מגבלת קרדיטים (תקרת עלות חודשית נשארת) |
| מסלולים | free_trial, creator_lite/pro, starter_social, digital_core/pro, total_dominance (+ basic/premium/vip הישנים) |
| חסימות | טייס אוטומטי: מ-creator_lite. דומיין עצמאי: מ-digital_core. תקציב ממומן: digital_pro+ |
| קרוסלה (כמה תמונות) | פייסבוק (אלבום) ואינסטגרם (קרוסלה עד 10). נבדק מול מוק של Graph API — **לא נבדק מול Meta חי** |
| טייס אוטומטי | מכין 3 פוסטים בשבוע לאישור (`pending_approval`). לא מפרסם לבד |
| לידים | `POST /api/leads/capture`, התראה במייל (Resend) ו/או webhook עם `tel:` ו-`wa.me` |
| סליקה | קישור תשלום לכל מוצר + webhook (ראו למטה) |
| חלוקת תקציב חכמה | מחשבת חלוקה שבועית לפי עלות לפנייה/קליק, עם הסבר בעברית |
| אתר + SEO | אתר קטן ב-`/s/<key>`, מאמרי SEO, מפת אתר, קרדיט "Powered by BOOL" |
| תמיכה | צ'אט AI + פניות לצוות (טאב "ניהול") |
| דומיינים | `bool.co.il` → אתר שיווקי, `app.` → דשבורד, `api.` → API בלבד; CORS לדומיינים של BOOL/ROCCA |

## מה לא נבנה / מה שונה מהמפרט (בכוונה)
1. **מיגרציית SQL (`002_bool_platform_setup.sql`) לא נכתבה.** המערכת שומרת נתונים כמסמכים (טבלת `documents` יחידה ב-Neon), לא בטבלאות `users/posts`. כל השדות שביקשתם (tier, credits_balance, commitment_months, subscription_cycle, country, city, currency, language, autopilot_enabled, ad_budget_monthly, ad_auto_distribute, ad_platforms_enabled; leads; campaign_logs_and_insights; client_websites; support_tickets) קיימים כמסמכים לכל עסק. מעבר לטבלאות יחסיות הוא פרויקט נפרד.
2. **ROCCA הוא כבר ה-Seed Tenant** (החשבון הראשי): ללא שינוי בנתונים. מסלולו `PLAN_TIER` (ברירת מחדל `total_dominance`). הטייס האוטומטי שלו כבוי עד שתדליקו אותו בלשונית "ראשי".
3. **תשלומים:** לא נבחרה חברת סליקה. לכל מוצר מגדירים `CHECKOUT_LINK_<SKU>` (עמוד תשלום מאוחסן אצל הספק) ואת `PAYMENT_WEBHOOK_SECRET`; הספק קורא ל-`POST /api/billing/webhook` עם `ref` ו-`paymentRef`. בלי זה, "לרכישה" מחזיר הודעה שהסליקה לא הוגדרה, והמפעיל יכול להפעיל חבילה ידנית בטאב "ניהול". חידוש מנוי = webhook נוסף; אם לא הגיע תוך מחזור+3 ימים, החשבון חוזר ל-free (הקרדיטים נשמרים).
4. **הוצאת כסף על מודעות:** המנוע **ממליץ** על חלוקה ומסביר; הוא לא מפעיל קמפיינים ולא מוציא כסף. זה דורש הרשאת `ads_management` ממטא (App Review) וחיבור Google Ads. הנתונים נכנסים כרגע ידנית (טופס "הזנת נתוני שבוע").
5. **טיקטוק, גוגל ובוט מענה 24/7 (Total Dominance):** לא נבנו. מסומנים "בקרוב" בקטלוג. טיקטוק/X/אתר חיצוני רצים על פרטי הגישה של המפעיל ולכן חסומים ללקוחות אחרים.
6. **דומיין עצמאי:** הלקוח מבקש, המפעיל מפנה DNS ומאשר (`POST /api/admin/sites/:id/domain/activate`). רישום דומיין ללקוח לא אוטומטי.
7. **גרפים:** חלוקת התקציב מוצגת כסרגל מוערם ולא עוגה (עוגה מקשה על השוואה).
8. **קרדיט הקישור באתרים** מפנה ל-rocca.co.il כקישור רגיל (follow) כפי שביקשתם. אתרים רבים שמקשרים לאותו אתר מאותו מקום יכולים להיחשב אצל גוגל כ"תכנית קישורים". אם תראו ירידה בדירוג — `BOOL_CREDIT_NOFOLLOW=true`.

## החלטות שעדיין פתוחות אצלכם
- האם המחירים כוללים מע״מ (`PRICES_VAT_NOTE` מציג את זה ללקוח).
- כמה קרדיטים בכל מנוי: הנחתי שבועי 10, לייט 40, פרו 100 (`billing.ts`).
- מחיר ל-Starter Social (לא צוין, ולכן לא נמכר כרגע).
- ספק הסליקה.
