# הקמת עותק ללקוח (שלב ניסיון)

כל לקוח בשלב הניסיון מקבל עותק משלו של הבוט. אפשר להקים עותק חדש תוך כ-20 דקות.

## מה צריך מהלקוח
- עמוד פייסבוק עסקי + חשבון אינסטגרם עסקי מחובר לעמוד, והלקוח מנהל של שניהם.
- חשבון פייסבוק אישי להתחברות.

## מה עושה בעל המערכת (פעם אחת לכל לקוח)
1. **Meta:** באפליקציה, App roles, Roles, Add People: להוסיף את הלקוח כ-**Tester** (הוא מאשר את ההזמנה בפייסבוק). בשלב הציבורי (אחרי App Review) השלב הזה לא יידרש.
2. **Neon:** פרויקט חדש (או מסד נוסף בפרויקט הקיים), להעתיק את ה-Connection string.
3. **Render:** New, Blueprint (אותו ריפו), שם שירות חדש. בשדות הסביבה:
   - `ANTHROPIC_API_KEY`, `DASHBOARD_TOKEN` (קוד כניסה ללקוח, להמציא), `DATABASE_URL`
   - `META_APP_ID`, `META_APP_SECRET`, `META_LOGIN_CONFIG_ID` (אותם ערכים כמו בעותק הראשי)
   - `PUBLIC_URL` = כתובת השירות החדש
   - `PLAN_TIER` = `basic` / `premium` / `vip`
   - `REQUIRE_PROFILE` = `true`
4. **Meta:** להוסיף את כתובת השירות החדש ל-**Valid OAuth Redirect URIs** (`<כתובת>/auth/facebook/callback`) ול-**App domains**. לגשת ל-Enter אחרי כל כתובת, ו-Save.

## מה עושה הלקוח (דקה-שתיים)
1. נכנס לכתובת השירות עם קוד הכניסה.
2. לשונית **הגדרות**: ממלא את פרטי העסק, "צור לי קול מותג", שומר.
3. באותה לשונית: "התחבר לפייסבוק ואינסטגרם" ומאשר.
4. לשונית **תוכנית**: בונה תוכנית פרסום ראשונה.

## הערות
- ב-Render החינמי השירות "נרדם" אחרי חוסר פעילות (התעוררות עד 50 שניות). פרסום מתוזמן דורש שירות ער: לשקול מסלול בתשלום (Starter) ללקוח אמיתי.
- סודות (מפתחות, טוקנים, מחרוזות חיבור) נכנסים רק לשדות ב-Render, לעולם לא לצ'אט.
