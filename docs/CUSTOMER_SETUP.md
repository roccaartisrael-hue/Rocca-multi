# הקמת עותק ללקוח (שלב ניסיון)

כל לקוח בשלב הניסיון מקבל עותק משלו של הבוט. אפשר להקים עותק חדש תוך כ-20 דקות.

## מה צריך מהלקוח
- עמוד פייסבוק עסקי + חשבון אינסטגרם עסקי מחובר לעמוד, והלקוח מנהל של שניהם.
- חשבון פייסבוק אישי להתחברות.
- (אופציונלי) פרטי העסק: מה מוכר, למי, באיזה טון.

## מה עושה בעל המערכת (פעם אחת לכל לקוח)
1. **Meta:** באפליקציה, App roles, Roles, Add People: להוסיף את הלקוח כ-**Tester** (הוא מאשר את ההזמנה בפייסבוק). אחרי App Review הצעד הזה לא יידרש.
2. **Neon:** פרויקט חדש (או מסד נוסף), להעתיק את ה-Connection string.
3. **Supabase (להעלאת תמונות וסרטונים):** bucket ציבורי חדש (למשל `media-<לקוח>`) באותו פרויקט, או פרויקט נפרד. ראו `MEDIA_SETUP.md`.
4. **Render:** New, Blueprint (אותו ריפו), שם שירות חדש. משתני סביבה:
   - `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` (אופציונלי), `DASHBOARD_TOKEN` (קוד כניסה ללקוח, להמציא)
   - `DATABASE_URL`
   - `META_APP_ID`, `META_APP_SECRET`, `META_LOGIN_CONFIG_ID` (אותם ערכים כמו בעותק הראשי)
   - `PUBLIC_URL` = כתובת השירות החדש
   - `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `SUPABASE_BUCKET`
   - `PLAN_TIER` = `basic` / `premium` / `vip`
   - `REQUIRE_PROFILE` = `true` (חוסם יצירת תוכן עד שהעסק הוגדר)
   - `OPERATOR_NAME`, `CONTACT_EMAIL` (לדפי מדיניות הפרטיות)
   - `GEMINI_MODEL` להשאיר ריק (זיהוי אוטומטי)
5. **Meta:** להוסיף את כתובת השירות החדש ל-**Valid OAuth Redirect URIs** (`<כתובת>/auth/facebook/callback`) ול-**App domains** (בלי https). ללחוץ Enter אחרי כל כתובת ו-Save.
6. לוודא שהשירות עלה: `/api/health` מחזיר OK.

## מה עושה הלקוח (דקה-שתיים)
1. נכנס לכתובת השירות עם קוד הכניסה.
2. לשונית **הגדרות**: ממלא את פרטי העסק, "צור לי קול מותג", ו"למד את השוק שלי", ושומר.
3. באותה לשונית: "התחבר לפייסבוק ואינסטגרם" ומאשר.
4. לשונית **תוכנית**: בונה תוכנית פרסום ראשונה, ומאשר.

## בדיקת קבלה (לפני שמוסרים ללקוח)
- הגדרות מציגות: אחסון "מסד נתונים קבוע", ג'מיני (או "לא מחובר"), וחיבור פייסבוק + אינסטגרם.
- יוצרים טיוטה, מעלים תמונה בכפתור 📎, ומוודאים שהכול עובד. לא מפרסמים ברשת של הלקוח בלי אישורו.

## הערות
- ב-Render החינמי השירות "נרדם" אחרי חוסר פעילות (התעוררות עד 50 שניות). פרסום מתוזמן דורש שירות ער: ללקוח אמיתי כדאי מסלול Starter של Render.
- סודות (מפתחות, טוקנים, מחרוזות חיבור) נכנסים רק לשדות ב-Render, לעולם לא לצ'אט.
- מגבלות הניסיון: ללא תשלום אוטומטי וללא הרשמה עצמית. ראו `ROADMAP.md` (שלב 4).

## רשימת בדיקת קבלה ללקוח משלם (לפני המסירה)
**הפרדה (חובה):**
- [ ] מסד נתונים נפרד (Neon) ו-bucket נפרד (Supabase). ב-Render: `DATABASE_URL` ו-`SUPABASE_BUCKET` של הלקוח בלבד.
- [ ] `REQUIRE_PROFILE=true`, והלקוח הגדיר עסק משלו (הגדרות). בדיקה: פוסט שנוצר מדבר על העסק שלו ולא על ROCCA.
- [ ] חיבור פייסבוק: העמוד והאינסטגרם של הלקוח (הגדרות מציגות את שמם).
- [ ] `DASHBOARD_TOKEN` ייחודי ללקוח (לא של ROCCA), נמסר לו בנפרד.
- [ ] `PLAN_TIER` נכון (למשל `vip`), ובשימוש: תקרת עלות ומכסות מוצגות בלשונית תוכנית.

**תפקוד (בדיקה אחת מול השנייה):**
- [ ] יצירת טיוטה ב-⚡ Gemini וב-⭐ Claude, ושתיהן עובדות.
- [ ] העלאת תמונה וסרטון (📎) מצליחה.
- [ ] תזמון אוטומטי וידני מציגים תאריכים נכונים (שעון ישראל).
- [ ] תוכנית פרסום ומסע פרסום מקצועי נוצרים (VIP), עם חלוקת תקציב.
- [ ] פרסום בדיקה אחד **באישור הלקוח** (פוסט אמיתי קצר, ואז מחיקה אם הוא מבקש).
- [ ] דפי מדיניות: `/legal/privacy` ו-`/legal/terms` נפתחים עם שם המפעיל והמייל.

**אמינות (לפני שמעבירים כסף):**
- [ ] שירות Render במסלול שלא "נרדם" (Starter), כדי שפרסום מתוזמן יצא בזמן.
- [ ] גיבוי: Neon שומר היסטוריה; בדיקה שהלקוח יודע למי לפנות בתקלה.
- [ ] הסכם בכתב: מי משלם על מה (AI, Render, Neon), בעלות על התוכן, ביטול.
- [ ] הוראות קצרות ללקוח (דף אחד): איך נכנסים, איך יוצרים תוכנית, למי פונים.

## Blueprint נפרד ללקוח (מונע דריסה של ROCCA)
ב-Render, `render.yaml` מזוהה עם השירות הקיים `rocca-social-bot`, ו-Render מציע "Associate existing services" (עדכון השירות של ROCCA). **לא לבחור בזה.**
לשירות לקוח משתמשים בקובץ נפרד: **`render.lugasi.yaml`** (שירות `lugasi-gallery-bot`, תוכנית Starter, `REQUIRE_PROFILE=true`, `PLAN_TIER=vip`).
- ב-Render: New, Blueprint, מאגר `Rocca-multi`, ענף `main`, **Blueprint Path: `render.lugasi.yaml`**.
- אם יוצא "Associate existing services", לבחור **"Create all as new services"**.
- ללקוח אחר: להעתיק את הקובץ ולהחליף את שם השירות ואת `PUBLIC_URL`.
