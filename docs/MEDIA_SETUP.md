# העלאת תמונות וסרטונים (Reels) מהאפליקציה

אינסטגרם ופייסבוק מורידים את הקובץ מקישור ציבורי. כדי שאפשר יהיה להעלות ישירות מהאפליקציה (מהטלפון או מהמחשב), צריך מקום אחסון. ההמלצה: **Supabase Storage** (חינם, 1GB, קובץ עד 50MB).

## הקמה (פעם אחת, כ-10 דקות)
1. supabase.com, התחברות עם GitHub, **New project** (שם `rocca`, אזור Frankfurt, סיסמה כלשהי ולשמור אותה בצד).
2. בתפריט: **Storage**, **New bucket**: שם `media`, לסמן **Public bucket**, ליצור.
3. **Project Settings, API**: להעתיק את **Project URL** ואת מפתח **service_role** (סודי! לא לשלוח בצ'אט ולא לצלם).
4. ב-Render, Environment:
   - `SUPABASE_URL` = ה-Project URL
   - `SUPABASE_SERVICE_KEY` = מפתח ה-service_role
   - `SUPABASE_BUCKET` = `media`
5. Save, rebuild, deploy.

## שימוש
בכל מקום שיש שדה "תמונה או סרטון" (פוסט חדש, טיוטה, תוכנית) מופיע כפתור **📎 העלאת תמונה או סרטון**. בוחרים קובץ, הוא עולה, והקישור נכנס לשדה אוטומטית.
- **סרטון MP4/MOV** מתפרסם באינסטגרם כ-**Reel** ובפייסבוק כסרטון. תמונה מתפרסמת כתמונה.
- בלי הגדרת Supabase אפשר עדיין להדביק קישור ישיר לקובץ.

## מפרט מומלץ לסרטון (Reel)
- פורמט **MP4 (H.264, שמע AAC)**, יחס **9:16** (לאורך), **1080x1920**, עד דקה.
- **גודל עד 50MB.** סרטון מהטלפון לרוב גדול מזה: כדאי לצלם ב-1080p (ולא 4K), או לכווץ (למשל באפליקציית CapCut, או בייצוא "1080p"). באייפון: הגדרות, מצלמה, הקלטת וידאו, 1080p ב-30 פריימים.
- אינסטגרם מעבדת סרטון עד כמה דקות. האפליקציה ממתינה עד כ-5 דקות לפני שהיא מדווחת על כשל.
